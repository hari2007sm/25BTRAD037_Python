# 25BTRAD037_Python

Python coursework repository containing lab exercises, problem solving scripts, and experiential learning projects.

## Repository Structure

- **`25BTRAD037_Experiential Learning Activity/`**: Course experiential learning projects, including CampusFind (Smart College Lost and Found System) and UI screenshots.
- **`25BTRAD037_Lab Exercises/`**: Python laboratory experiment exercises (EXP 01 through EXP 17).
- **`25BTRAD037_Problem Solving/`**: Python practical problem-solving assignments (Attendance Tracker, Bill Generator, OTP Generator, Sales Data Analysis, Student Grade Management, Unit Converter, etc.).
