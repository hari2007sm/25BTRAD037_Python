# 25BTRAD037_Python

Python coursework repository containing lab exercises, problem solving scripts, and experiential learning projects.

## Repository Structure

- **`USN_Experiential Learning Activity/`**: Course experiential learning projects, including CampusFind.
- **`USN_Lab Exercises/`**: Python laboratory experiment exercises (EXP 01 through EXP 17).
- **`USN_Problem Solving/`**: Python practical problem-solving assignments (Attendance Tracker, Bill Generator, OTP Generator, Sales Data Analysis, Student Grade Management, Unit Converter, etc.).
